关于《班务云脑》

作品定位

《班务云脑》是一款面向班主任的AI智能班级管理中枢，围绕"学生档案—考勤—成绩—积分—排座—AI助手"构建班级治理数字闭环。以"云脑"为意象，寓意用数据与AI驱动班级管理从经验走向科学，让每一位班主任减负增效。

核心算法
  • 六维综合素养模型：学业/纪律/卫生/文体/劳动/品德加权评分 + Canvas雷达图画像
  • 智能排座引擎：身高递减×近视前置×男女均衡×学业互补多约束优化
  • 学情预警算法：考勤连续异常 + 成绩退步 + 积分负值三雷达扫描
  • AI评语引擎：融合积分流水与素养画像，为每生生成个性化期末评语
技术特性
  • 原生 HTML / CSS / JavaScript，零外部依赖，双击即用
  • localStorage 本地持久化 + JSON 数据导入导出
  • 深色科技风数据驾驶舱 + Canvas 可视化
  • AI班务智能体：内置治理知识库，支持一键配置免费大模型API
